Privasi

Draf kebijakan produk berdasarkan perilaku aplikasi saat ini. Pemilik perlu meninjau identitas pengelola, kontak resmi, masa retensi, dan kewajiban hukum sebelum menjadikannya kebijakan final.

KITA TABUNG memproses data yang diperlukan agar fungsi keuangan pribadi dapat berjalan. Kami tidak membuat klaim sertifikasi keamanan atau enkripsi khusus yang tidak dapat dibuktikan dari implementasi saat ini.

Data yang diproses

  • Email dan metadata profil untuk autentikasi akun.
  • Dompet, saldo, transaksi, budget, tagihan berulang, target tabungan, tanggal gajian, dan pengaturan aplikasi.
  • Metadata hasil scan struk seperti merchant, nominal, kategori, waktu, dan confidence. Foto asli tidak dimasukkan ke backup finansial aplikasi.
  • Riwayat chat AI yang disimpan oleh aplikasi bila fitur digunakan.

Penyimpanan

Data finansial akun disinkronkan melalui Supabase dan juga dapat memiliki cache lokal di browser. Backup manual diunduh sebagai file JSON ke perangkat pengguna. Jangan membagikan file backup kepada pihak yang tidak dipercaya.

AI dan scan struk

Permintaan AI dan foto struk yang diproses dikirim melalui endpoint server aplikasi ke layanan model yang dikonfigurasi. AI menghasilkan rekomendasi atau draft; pengguna tetap mengonfirmasi sebelum catatan finansial dibuat atau diubah.

Hak dan penghapusan

Aplikasi menyediakan reset data finansial. Penghapusan akun autentikasi sepenuhnya belum tersedia sebagai self-service pada antarmuka saat draf ini dibuat. Lihat halaman Penghapusan Data untuk prosedur dan keterbatasan saat ini.

Keamanan akun

Jangan membagikan OTP, password, PIN AI, file backup, atau informasi kartu/rekening lengkap. Gunakan hanya domain resmi KITA TABUNG saat masuk atau memverifikasi akun.
