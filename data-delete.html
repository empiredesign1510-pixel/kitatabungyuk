Penghapusan Data

Halaman ini menjelaskan kemampuan produk saat ini. Waktu pemrosesan bantuan manual dan kebijakan retensi administratif tetap perlu ditetapkan pemilik.

Reset data finansial

Pengguna yang sudah masuk dapat membuka Pengaturan → Zona Berbahaya → Reset Semua Data. Tindakan ini menghapus state keuangan akun dari penyimpanan cloud yang digunakan aplikasi dan mereset data lokal aplikasi.

Penghapusan akun autentikasi

Pengguna yang sudah masuk dapat memilih Pengaturan → Zona Berbahaya → Hapus Akun Permanen. Fitur ini menghapus data finansial cloud lalu identitas akun autentikasi melalui endpoint server yang hanya menerima sesi pengguna yang valid. Jika backend penghapusan belum dikonfigurasi oleh pemilik aplikasi, tombol akan menampilkan pesan konfigurasi dan penghapusan penuh perlu dibantu pengelola.

Sebelum menghapus

Unduh backup manual jika kamu masih memerlukan salinan transaksi, budget, target, atau tagihan. Setelah reset atau penghapusan final, pemulihan tidak dijamin.
